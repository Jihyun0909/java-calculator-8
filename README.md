# 문자열 덧셈 계산기 (String Add Calculator)

## 프로그램 구조 (MVC 기반)

| 계층 | 클래스 | 역할 |
|------|---------|------|
| Application | `Application` | 프로그램 진입점 (main 메서드) |
| Controller | `CalculatorController` | 사용자 입력 → 계산 호출 → 결과 출력의 전체 흐름 제어 |
| Service | `StringAddCalculator` | 계산 로직 담당 (빈 문자열, 구분자 파싱, 합계 계산) |
| Support | `InputParser`, `Validators` | 입력 파싱 및 검증 유틸리티 |

---

## 구현할 기능 목록

### 1. 입력 안내 및 결과 출력
- 콘솔에 `"덧셈할 문자열을 입력해 주세요."` 메시지를 출력한 뒤 입력을 받는다.
- 결과 출력 시 `"결과 : <합>"` 형식을 준수한다.
  - 예: `결과 : 6`

---

### 2. 빈 문자열 처리
- 입력값이 `""`(빈 문자열) 또는 `null`이면 결과는 `0`을 반환한다.

---

### 3. 기본 구분자 파싱
- 쉼표(`,`) 또는 콜론(`:`)으로 구분된 문자열을 분리한다.
  - `"1,2"` → `3`
  - `"1,2:3"` → `6`

---

### 4. 커스텀 구분자 파싱
- `"//<구분자>\n<숫자들>"` 형식을 지원한다.
  - `"//;\n1;2;3"` → `6`
- 커스텀 구분자는 정규식 안전 처리(`Pattern.quote()`)로 구현한다.

---

### 5. 유효성 검증
- 숫자가 아닌 토큰이 포함되어 있으면 `IllegalArgumentException` 발생.
- `0` 이하의 값이 포함되어 있으면 `IllegalArgumentException` 발생.
- 예외 발생 시 프로그램은 종료되어야 한다. (`System.exit()` 사용 금지)

---

### 6. 합계 계산
- 검증을 통과한 모든 양수를 합산해 결과를 반환한다.
